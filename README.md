# Retail Sales Data Analyzer

## About the Project

Retail Sales Data Analyzer is a beginner-friendly Python project
that analyzes retail sales data and displays useful information
about products, categories, and sales trends.

## Features

- Load sales data from a CSV file
- Check missing and invalid values
- Calculate total and average sales
- Find the most popular product
- Filter data by product, category, and date
- Display a sales summary
- Calculate sales growth
- Generate bar charts and line graphs
- Create a correlation heatmap

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Files

- `retail_analyzer.py` - Main Python program
- `retail_sales.csv` - Sample sales dataset
- `README.md` - Project documentation
